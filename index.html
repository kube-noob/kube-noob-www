What it does

Audit

Rules with strict schemas for Kubernetes, Routes, SCCs, EgressFirewall, Gateway API and StackRox; removed APIs; safe auto-fixes. Findings carry a rule id, a line, the NIST control and the fix. SARIF and OSCAL out.

Try it

Debug

Offline playbooks, read-only steps first, redacted evidence bundles, and read-only cluster evidence that never touches Secrets. The text view shows the ten lines you act on.

Try it

Known bugs

Errors matched to the issues in the OpenShift release notes, with the fix version and workaround -- and, when your release is outside the index it holds, it says so instead of returning an empty list.

Try it

Policy

Why was this denied? Kyverno, Gatekeeper, VAP, Pod Security, SCC, RHACS, quota and RBAC, with the smallest fix. Can A reach B? AdminNetworkPolicy, NetworkPolicy, BaselineAdminNetworkPolicy and ClusterNetworkPolicy evaluated in cluster order, naming the tier and rule that decided; an undocumented CNI leaves the verdict undetermined rather than guessing.

Try it

Blast radius

If this workload is compromised, what can it reach? Exposure, token, RBAC, Secrets and node, each reached, none or not determined, as JSON or a Mermaid diagram.

Read it

Evidence

One self-contained HTML page a reviewer opens with no network, an alert turned into a stored report, SARIF, OSCAL assessment-results and the FedRAMP 20x KSI crosswalk.

Read it

Generate

Hardened manifests, Helm charts and admission policies from a blueprint, audited again before they are returned; remaining high or critical findings mark the result blocked.

Read it

Learn

Walk a request through your own manifests, one hop at a time. A hop nothing read is never reported as working.
