How to read this page
  • ✓ holds a rule read this hop and found nothing wrong.
  • ✗ BROKEN a rule on this hop produced a finding. The walk carries on.
  • ? cannot judge nothing could answer for this hop. The walk stops here.
  • ◌ not observable no manifest can show this hop. It is never counted as passing, and what stands there in the diagram is drawn dashed and marked not in any manifest.
  • · not walked the walk stopped before this hop. It is never reported as working.
  • shaded text came from your manifests; everything else is kube-noob speaking.
  • Green is used for one thing: a hop that holds. The colour of a card that has no verdict yet says what kind of object it is, and nothing about whether it works.
